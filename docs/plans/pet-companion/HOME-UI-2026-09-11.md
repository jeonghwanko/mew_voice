# 뮤 보이스 고양이 중심 홈 개편

## 계획 리뷰와 결정

사용자 레퍼런스는 캐릭터가 가장 아래 시각 레이어를 차지하고 UI가 주변에 겹치는 배치 참고다. 첨부 화면의 의상·문구·상품 기능을 그대로 복제하지 않는다.

- 홈의 기본 상태는 전체 높이 고양이 무대. 기존 대화 입력은 접을 수 있는 패널로 옮긴다.
- 좌측 말 걸기 → `/meow`(보호자 목소리로 야옹 생성), 울음 듣기 → `/capture?mode=audio`, 사진 살피기 → `/capture?mode=photo`. AI 답변 TTS와 울음 해석을 구분한다.
- 하단은 홈 / 기록 / 상점. 대화·아이 관리의 기존 경로는 유지하고 메뉴/기록에서 연결한다.
- 상단 좌측 재화는 미연결 상태 `—`, 누르면 준비 안내. 우측 메뉴에는 공지, 우편, FAQ, 친구 초대, 우리 아이, 설정.
- 재화 원장·결제·우편·공지 서버는 현재 계약에 없다. 가짜 잔액/상품 가격/공지/미읽음 배지 없이 준비 상태를 제공한다. 친구 초대는 검증된 앱 링크를 사용한 시스템 공유이며 추천인 적립·가족 권한 부여가 아니다.
- 기존 고양이 아트 작업과 파일을 보존한다. 이 UI 변경이 기존 미채택 3D 모델의 아트 승인이나 새 모델 통합 완료를 의미하지 않는다.

## 구현 순서

1. 공용 선형 아이콘과 퀵 액션 일러스트 3종 제작·번들 적용.
2. 홈 전체 무대, 좌측 퀵 액션, 상단 재화/메뉴, 접이식 대화·꾸미기 패널.
3. 하단 3개 탭과 상점 준비 화면, 공지·우편·FAQ·초대 패널. 기존 아이 관리/대화/체크인 접근 유지.
4. capture 모드 딥링크: 명시한 모드와 충돌하는 미완료 초안은 덮어쓰지 않고 같은 모드로 돌아갈 때 복원.
5. 타입 검사, lint, 전체 모바일 Jest, Android/web export. 웹에서 작은 화면/표준 화면/태블릿, 메뉴·탭·퀵 액션·대화·꾸미기·초대 동작 확인.

## 디자인과 완료 기준

- 기존 cream/sage 스튜디오 토큰, 부드러운 면과 둥근 선. 3개 핵심 행동은 동일 스타일 PNG, 작은 내비게이션은 24px SVG와 텍스트 라벨.
- 탭바 safe area, 최소 44px 터치 영역, 선택/펼침 접근성 상태, 긴 내용 스크롤, 닫기·Android 뒤로가기 제공.
- 첫 홈에서 고양이·3개 퀵 액션·상단·탭바가 함께 보인다. 입력/긴 답변은 확장 패널에서 읽는다.
- 권한은 퀵 액션 진입 자체가 아니라 기존 촬영/녹음 버튼에서 요청한다.
- 웹 UI 검증과 네이티브 실기기 GL/마이크/카메라 검증을 구별해 보고한다. 이 요청에 스토어 배포는 포함하지 않는다.

## 후속 서비스 구현

재화 명칭/지급·사용 정책 확정 → 서버 원장과 동시성/환불 → 상품·소유권·스토어 결제 검증 → 운영 공지/우편 수신·읽음 → 초대 코드·보상 정책. 이번 UI에는 해당 기능이 준비 중임을 명시한다.

## 구현·검증 결과

- 계획 1–4 구현 완료. 원본 생성 PNG 3종, 160×160 런타임 PNG 3종(합계 90,309 bytes), 원본 선형 SVG 아이콘 15종을 적용했다. 생성 프롬프트: `apps/mobile/assets/ui/quick-actions/README.md`.
- `npm run typecheck`, `npm run lint`(경고 0), `npm test -- --watchman=false`(7 suite / 33 tests) 통과.
- web export `dist/home-ui`(1,393 modules), Android Hermes export(1,710 modules) 통과. 최초 Android 시도는 sandbox의 hermesc.exe 실행 권한 때문에 실패했고 승인된 재실행으로 통과했다.
- `node scripts/verify-mewvoice-home.mjs` 통과: 320/360/390/820px 홈과 44px 버튼, 공지/우편/FAQ/공유 미지원 대안/재화, 3개 퀵 액션, 체험 질문·답변, 기록/상점 탭, 상점→꾸미기→홈 복귀. 실제 API 요청은 차단한 로컬 체험 검증이다. 실제 공유 전송은 실행하지 않았다.
- `apps/mobile/output/home-ui/`에 홈 4개 크기, 메뉴, FAQ, 대화, 기록, 상점 스크린샷 및 verification.json을 보관한다. 주요 화면 이미지를 직접 확인했다.
- `node scripts/verify-mewvoice-home.mjs --serve`로 `http://127.0.0.1:4193` 미리보기. 첫 화면의 `체험으로 살펴보기`로 홈 진입.
- `adb devices` 연결 기기 없음. 네이티브 카메라·마이크·GPU·키보드·스크린리더·큰 글꼴은 실기기 확인이 남아 있다. 기존 상세 화면의 dark/sky 스타일은 이번 개편 범위 밖이다. 스토어 배포하지 않았다.
- 초대 링크 확인: Google Play `gg.pryzm.union` 공개 목록이 아직 이전 이름 `찾아줘-동네친구`인 상태이므로 화면에 업데이트 공개 전 안내를 넣었다.
