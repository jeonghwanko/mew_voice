## 배포 전 필요한 설정

API 호스트에 FFmpeg가 필요하다. 기본 실행 이름은 `ffmpeg`, 다른 경로는 `COMPANION_FFMPEG_PATH`로 설정한다. 미설치 시 오디오 업로드는 503으로 차단한다. FFmpeg 자식 프로세스는 셸 없이 실행하며 네트워크 프로토콜을 허용하지 않는다. 프로세스별 동시 디코더 2개, 15초 실행 제한, 약 1.6MB 출력 제한을 적용했다. 이 전처리의 부하를 운영 환경에서 측정하고 규모가 커지면 업로드 전처리 전용 worker로 분리해야 한다.

## 남은 출시 검증

- 실제 Android/iOS의 M4A·WebM 녹음, 백그라운드 복귀·오디오 인터럽트 검증.
- 실제 Gemini 호출과 운영 보존 정책, 부하/잔존 테스트.
- PROCESSING 상태에서 worker가 강제 종료될 때 재처리 복구 및 업로드·큐 저장 사이 장애 검증.
- 관찰·대화 50건 이후 페이지 처리, 웹의 고양이 삭제·내보내기·분석 재시도 UI.
- 공용 admin.ts에 아직 남은 옛 관리 API는 화면 삭제와 별개로 유지 중. 완전 폐기는 혼합 서비스·DB 참조 분리 후 진행해야 한다.
- 웹의 한국어 하드코딩을 기존 i18n 체계로 옮기는 작업.

운영 DB 변경, 실제 AI 호출, 배포는 이번 리뷰에 포함하지 않았다. 전체 공용 API 테스트를 통과했다고 주장하지 않는다.
